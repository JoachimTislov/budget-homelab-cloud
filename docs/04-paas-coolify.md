# Turnkey Self-Hosted PaaS: Coolify v4

If your primary goal is to run web services, APIs, databases, cron jobs, and internal tools with the developer velocity of **Heroku, Render, or Vercel** without the cognitive overhead of writing complex Kubernetes YAML manifests, **Coolify v4** is the premier open-source solution for cheap local hardware.

---

## 1. Why Coolify Excels on Cheap Local Hardware

- **Low System Resource Overhead:** Uses plain Docker and SSH under the hood. Does not require heavy daemon agents or distributed consensus mechanisms. Idles at **~200 MB to 400 MB RAM**.
- **Multi-Server Orchestration:** A single Coolify dashboard can manage dozens of remote local servers, mini-PCs, or VPS instances over simple SSH keys.
- **Built-in Developer Tooling:**
  - Git Push / Webhook auto-deployments (GitHub, GitLab, Gitea, or custom Git repos).
  - One-click databases with automated backups (PostgreSQL, MySQL, MariaDB, MongoDB, Redis, ClickHouse).
  - Traefik reverse proxy with automated Let's Encrypt SSL certificates.
  - One-click application templates (Next.js, FastAPI, WordPress, Ghost, Plausible, Vaultwarden, etc.).

---

## 2. Prerequisites

- A clean installation of **Ubuntu 22.04 / 24.04 LTS** or **Debian 12** on bare metal, inside a Proxmox VM, or inside an unprivileged LXC container with Docker nesting enabled.
- Minimum Specs: **2 vCPUs, 2 GB RAM, 20 GB Disk Space**.

---

## 3. Installation in One Command

SSH into your target machine or container and execute the official automated installer:

```bash
curl -fsSL https://cdn.coollabs.io/coolify/install.sh | bash
```

The script will automatically:
1. Verify system requirements and dependencies (`curl`, `wget`, `jq`).
2. Install Docker Engine and Docker Compose.
3. Pull Coolify core images and start the services.
4. Launch the web dashboard on port `8000`.

Once complete, open your browser and navigate to:
```
http://<YOUR_LOCAL_IP>:8000
```

---

## 4. Multi-Node Expansion with Cheap Mini-PCs

Coolify allows you to keep one mini-PC as the control plane dashboard and attach other cheap mini-PCs as worker compute nodes:

1. In the Coolify Dashboard, navigate to **Servers** -> **+ Add Server**.
2. Name the server (e.g., `mini-pc-worker-02`).
3. Enter the local IP address (`192.168.1.51`) and SSH port (`22`).
4. Paste the private SSH key generated by Coolify onto the worker machine's `~/.ssh/authorized_keys`.
5. Coolify will automatically configure Docker on the remote node and make it selectable as a deployment target when creating applications!
